# SweetCraft — WPF-приложение пекарни

## Структура и ответственность

- `Data/` — существующая EF6 Database First модель (`Model1.edmx`) и классы 15 сущностей, сгенерированные из SweetCraftDB.
- `Helpers/` — `ObservableObject` для уведомлений WPF, `RelayCommand` и конвертер отображения.
- `Services/` — доступ к каталогу, проверка и хеширование паролей, оформление заказов, работа с изображениями и административные CRUD-операции.
- `ViewModels/` — состояние экранов и `ICommand` для входа, каталога, корзины, личного кабинета и панели таблиц.
- `Views/` — отдельные WPF-окна каталога, корзины, профиля и управления БД; `MainWindow` — авторизация/регистрация.
- `Resources/Icons/` — XAML-векторный значок пекарни; палитра и общие стили WPF находятся в `App.xaml`.
- `ProductImages/` — каталог для изображений товаров; он создается при первом выборе файла.

## MVVM и база данных

Окна связывают элементы управления с ViewModel через binding. `ObservableObject` уведомляет UI об изменении свойств, `RelayCommand` связывает пользовательские действия с командами ViewModel. Слой `Services` изолирует операции предметной области и EF6. `SweetCraftDBEntities` использует EDMX Database First и именованную строку подключения `SweetCraftDBEntities` из `App.config`; транзакция оформления заказа атомарно создает заказ, позиции и историю статуса и очищает корзину.

Изображения копируются в `ProductImages` рядом с исполняемым приложением, а в поле `Products.ImagePath` сохраняется относительный путь. Пароли новых учетных записей хранятся как PBKDF2-хеш с индивидуальной случайной солью. Роли и таблицы должны быть заранее созданы в SQL Server; приложение не создает и не мигрирует схему.

## Запуск

Откройте `SweetCraft.slnx` в Visual Studio и проверьте строку подключения в `SweetCraft/App.config`. Проект использует .NET Framework 4.7.2 и установленный в репозитории Entity Framework 6.5.2.

Панель данных позволяет редактировать все прикладные сущности модели. Менеджер не видит `Users` и не может удалить записи; администратор получает таблицу `Users` и удаление. Удаление товара, встречающегося в заказах, запрещается с сообщением по требованию F4.
